# CloudVault

A secure cloud storage platform built with FastAPI, React, PostgreSQL, and Docker.

## Features

- JWT Authentication
- Secure File Uploads
- File Preview
- File Download
- Favorites
- Trash & Restore
- File Sharing
- Search Files
- Responsive Dashboard

## Tech Stack

Frontend
- React
- TypeScript
- TailwindCSS
- Vite

Backend
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL
- JWT Authentication

Deployment
- Vercel
- Render
- Neon PostgreSQL
